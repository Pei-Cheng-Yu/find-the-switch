# 尋找開關

燈，是誰關的？

[▶ 開始遊戲](https://pei-cheng-yu.github.io/find-the-switch/)

繁體中文 2D 懸疑點擊探索遊戲。黑暗、手電筒、貓咪，以及看似熟悉的家。

## 遊玩

使用電腦瀏覽器，移動滑鼠探索、點擊物件和房門。依底部角色獨白前進；從抽屜取得手電筒後，按下方開關啟用。可使用提示、靜音和減弱動態。

場景圖、CSS、JavaScript 和合成音效全部內嵌於單一 `index.html`，不需要安裝套件或伺服器，亦可下載後離線開啟。

## 設計

- 陰暗手繪場景與匹配事件插畫，共 28 張素材。
- 三次停電、安置貓咪、線索與鑰匙、總電源異變。
- 人影在暗處顯現，手電筒照到便消失；閒置也可能看見門影。
- 玄關鏡像與兩扇實體門；五秒未選門會從床上醒來。
- 玩家自己回書房座位後再次熄燈，自動開始下一輪。
- 瀏覽器自動保存、重新開始、三級提示與設定。

本作品透過與 AI 討論規格、圖像編修、程式實作及反覆試玩完成。
